# DHS Partner - AndroidIDE Project

This is a native Android WebView wrapper around the DHS Partner web app.

## Build in AndroidIDE
1. Extract this ZIP.
2. Open the extracted folder in AndroidIDE.
3. Wait for Gradle sync.
4. Run **Build > Assemble Debug APK**.
5. APK: `app/build/outputs/apk/debug/app-debug.apk`

The web app is bundled in `app/src/main/assets/`.
